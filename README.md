## 🚀 Projetos

### Sistema de gerenciamento para loja de carros

Sistema para controle de estoque automotivo, com cadastro de veículos, upload de fotos, login administrativo, controle de gastos e banco de dados relacional.

**Tecnologias:** Python, Flask, PostgreSQL, SQLAlchemy

---

### Sistema de Backup e Restauração

Aplicação desktop para criação e restauração de backups, com seleção de arquivos e pastas, compactação em `.zip`, restauração em destino escolhido e organização em camadas.

**Tecnologias:** Python, Tkinter / CustomTkinter, Pathlib, Shutil, Zipfile

---

### YouTube Downloader

Aplicação web para download de vídeos, com preview, escolha de qualidade e organização entre rotas e serviços.

**Tecnologias:** Python, Flask
